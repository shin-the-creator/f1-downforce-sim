# 물리 모델 설명 — 랩타임은 어떻게 계산되는가

랩타임 계산 과정을 단계별로 설명한다. 뒷부분에서 핵심 함수 3개를 **줄 단위로** 해설한다 (면접 대비).

> **읽는 법:** 본문은 고등학교 물리 — 원운동(구심력), 마찰력, 뉴턴 운동 법칙, 일과 에너지, 베르누이 법칙 — 만으로 이해할 수 있게 썼다.
> ⚙️ 표시가 붙은 부분은 "컴퓨터가 계산을 정확하게 하려고 쓰는 기법"이라 몰라도 결과를 이해하는 데 지장이 없다. 자세한 내용은 맨 끝 [심화 참고](#심화-참고-컴퓨터-계산-기법).

| 핵심 함수 | 파일 | 하는 일 |
|---|---|---|
| `cornerSpeed` | `src/physics/corner.ts` | 코너 최대 속도 (원운동 + 마찰) |
| `simulateLap` 의 `step`, `accel`, `decel` | `src/physics/lapsim.ts` | 가속·제동 계산 |
| `wingAero`, `carAero` | `src/physics/aero.ts` | 공기력 계산 |

모든 기본값과 가정은 [`assumptions.md`](assumptions.md) 에 있다.

## 1. 큰 그림: 준정상 상태 점질량 랩타임 시뮬레이션

```
셋업(윙·디퓨저·차고) ──► 공기력 계수 C_L·S, C_D·S ──┐
                                                    ▼
몬차 데이터 ──► 레이싱 라인 ──► 1 m 마다 곡률 κ ──► 각 점의 한계 속도
                                                    │
                     전진 계산(가속) + 후진 계산(제동) ◄┘
                                    │
                      더 작은 속도 택하기 ──► 시간 더하기 ──► 랩타임, 섹터, 에너지
```

- **점질량**: 차를 한 점으로 본다. 무게 이동·서스펜션·타이어 미끄럼각은 없다.
- **준정상 상태**: 각 점에서 "그 순간 낼 수 있는 최대 가속·제동·코너링"을 한다고 본다.
  실제 F1 팀이 셋업을 빠르게 비교할 때 쓰는 가장 기본적인 방법이다.

## 2. 서킷: 몬차

- 중심선 데이터: TUM racetrack-database (OpenStreetMap 기반, 5 m 간격, 좌우 트랙 폭 포함).
  길이 5,790 m 로 공식 길이 5.793 km 와 0.05 % 차이.
- **곡률 반지름**: 서킷을 1 m 간격 점으로 나누고, 각 점에서 "이 부분은 반지름 몇 m 짜리 원의 일부인가" 를 구한다.
  직선은 반지름이 무한대, 첫 시케인 같은 급코너는 약 10 m.
- **레이싱 라인**: 드라이버는 트랙 가운데가 아니라 바깥 → 안쪽 → 바깥으로 달려 코너를 완만하게(반지름을 크게) 만든다.
  그래서 트랙 폭 안에서 코너를 최대한 펴는 선을 컴퓨터가 반복 계산으로 찾는다 ⚙️.
  결과: 중심선 1:27.4 → 레이싱 라인 1:22.5 (기본 셋업). 실제 최적 주행선과 똑같지는 않은 **근사**다.

## 3. 공기력

모든 부품의 힘은 같은 식이다.

```
F_down = ½ ρ v² (C_L·S)        F_drag = ½ ρ v² (C_D·S)
```

`C_L·S`(계수 × 면적, 단위 m²)는 속도와 무관한 차의 성질이라, 부품별로 구해 더하면 된다.

### 3-1. 윙: 2차원 데이터 → 3차원 날개

`data/wing_data.csv` 의 CL, CD 는 **폭이 무한한 날개**의 값이다. 실제 윙은 폭이 유한해서
날개 끝에서 고압 쪽 공기가 저압 쪽으로 돌아 들어가고(날개 끝 와류), 그 결과

- 다운포스가 줄어든다: `C_L(3D) = C_L(2D) × AR / (AR + 2)`
- **유도항력**이 생긴다: `C_D(3D) = C_D(2D) + C_L(3D)² / (π e AR)`

(프란틀 양력선 이론, AR = 가로세로비). 유도항력이 C_L² 에 비례하므로
**다운포스를 키울수록 항력이 더 빨리 커진다** → 다운포스–항력 트레이드오프의 원인.

### 3-2. 바닥(디퓨저)·차고 — 정성적 경향을 표현한 가정 모델

```
C_L·S_floor = C_L·S_ref × f_h(차고) × f_θ(확장각)
C_D·S_floor = 0.08 × C_L·S_floor
```

**차고 함수** `f_h(h) = (h_ref / h)^n × 1 / (1 + e^{−(h − h_c)/w})` (기준 차고에서 1이 되게 나눔)

| 구간 | 모양 | 이유 |
|---|---|---|
| 차고가 낮아짐 | 증가 `(h_ref/h)^n` | 바닥과 지면 사이 통로가 좁아질수록 공기가 빨라지고(연속 방정식) 압력이 낮아짐(베르누이) |
| 임계 차고 h_c 아래 | 급감 (로지스틱 함수) | 통로가 너무 좁으면 흐름이 끊겨 다운포스가 사라짐. 실제 차에서는 떠올랐다 내려앉기를 반복하는 **포퍼싱** |

기본값에서 차고 25 mm 근처가 가장 빠르고, 18 mm 아래에서는 랩타임이 급격히 나빠진다.
진동 자체는 계산하지 않고 평균 다운포스 감소만 표현한다.

**확장각 함수** `f_θ(θ) = b + (1 − b) × (θ/θ_opt) × e^{1 − θ/θ_opt}`

- 각도를 키우면 바닥 아래 공기를 더 세게 빨아내 다운포스 증가.
- 최적 각도 θ_opt(12°)를 넘으면 디퓨저 벽에서 흐름이 떨어져(박리) 감소.
- b: 확장각 0° 인 평평한 바닥도 남기는 다운포스 비율.

### 3-3. 공력 밸런스 (선택, 가정 모델)

`밸런스 = 앞바퀴 쪽 다운포스 ÷ 전체 다운포스`.
최적값(45 %)에서 벗어나면 앞 또는 뒤 타이어가 먼저 한계에 도달한다(언더·오버스티어).
이를 `μ_eff = μ × (1 − k (밸런스 − 최적)²)` 로 단순화했다.
예: 기본 셋업(밸런스 49 %)에서 리어 윙을 키우면 밸런스가 뒤로 옮겨져 이 효과가 줄어든다.
몬차 리어 윙 최적 각도가 이 모델을 켜면 약 12°, 끄면 약 8° 로 바뀐다 — 가정 모델이 결과에 주는 영향.

## 4. 코너: 원운동 + 마찰 (발표의 출발점)

구심력 = 타이어 마찰력:

```
m v² / r = μ ( m g + ½ ρ v² C_L·S )
```

v² 로 정리하면

```
v_max² = μ g / ( 1/r − μ ρ C_L·S / (2m) )
```

- 다운포스 0: `v_max = √(μ g r)`
- 고속 코너(1/r 작음)일수록 분모에서 다운포스 항의 비중이 커서 **다운포스 이득이 크다**.
- 분모 ≤ 0: 다운포스가 구심력보다 빨리 커져서 미끄러지지 않음 → 직선 최고 속도가 한계.

## 5. 직선: 일률과 에너지

| 상황 | 운동방정식 |
|---|---|
| 가속 | `m a = min(P/v, 타이어 한계) − F_항력 − F_구름` |
| 제동 | `m a = −(타이어 한계 + F_항력 + F_구름)` |
| 최고 속도 | `P = (F_항력 + F_구름) × v` |

- `P/v`: 출력이 일정하면(일률 = 힘 × 속도) 느릴 때는 힘이 크고 빠를 때는 작다.
  출발 직후에는 P/v 가 타이어 한계보다 커서 바퀴가 헛돌 수 있으므로 타이어 한계로 자른다.
- **마찰원**: 코너에서 가속·제동하면 가로 힘(구심력)과 세로 힘이 마찰을 나눠 쓴다.
  `세로 최대 = √( (μN)² − (m v² κ)² )`, `N = m g + F_down`.

### 전진·후진 계산

1. 각 점의 한계 속도 = min(코너 최대 속도, 직선 최고 속도)
   (min = 둘 중 작은 값)
2. **전진**: 가장 느린 코너에서 출발해 최대 가속으로 다음 점 속도를 구한다 (`v₂² = v₁² + 2 a ds`).
3. **후진**: 거꾸로, 최대 제동으로 앞 점 속도를 구한다 (뒤에서 보면 "제동 = 가속").
4. 각 점에서 **한계, 전진, 후진 중 가장 작은 속도** = 실제 속도.
   전진이 작으면 가속 중, 후진이 작으면 제동 중이다.
5. 시간: 구간마다 `시간 = 거리 ÷ 평균 속력 = ds ÷ ((v₁ + v₂)/2)` 를 더한다.

> 가속도는 구간 처음과 끝에서 조금 다르므로, 두 값의 **평균 가속도**로 계산한다 ⚙️.
> 처음 값만 쓰면 코너를 빠져나올 때 가속이 한 칸씩 늦어져, 구간 길이를 바꿀 때마다 랩타임이 달라졌다.

### 에너지 (일–운동에너지 정리)

`W = ∫ F ds`. 구간마다 실제 속도 변화로 바퀴의 세로 힘을 거꾸로 구해
엔진이 한 일(+)과 브레이크가 흡수한 에너지(−)로 나눈다.

```
W_엔진 − W_브레이크 − W_항력 − W_구름 = ΔKE  (플라잉 랩이면 0)
```

기본 셋업 몬차 한 바퀴: 엔진 약 44 MJ = 항력 24 MJ + 브레이크 18 MJ + 구름 2 MJ.
테스트가 이 장부가 10⁻⁹ 이내로 맞는지 확인한다.

## 7. 핵심 함수 줄 단위 해설

### 7-1. 코너 속도 — `cornerSpeed` (`src/physics/corner.ts`)

```ts
export function cornerSpeed(kappa: number, mu: number, mass: number, cls: number, rho: number, g: number): number {
```
입력: 곡률 κ = 1/r, 마찰계수, 질량, 다운포스 계수 C_L·S, 공기 밀도, 중력가속도.

```ts
  const k = Math.abs(kappa);
```
왼쪽·오른쪽 코너 구분 없이 크기만 쓴다.

```ts
  const denom = k - (mu * rho * cls) / (2 * mass);
```
식의 분모 `1/r − μρC_L·S/(2m)`. 앞 항은 "코너가 요구하는 것", 뒤 항은 "다운포스가 도와주는 것".

```ts
  if (denom <= 0) return Infinity;
```
다운포스 도움이 더 크면 어떤 속도로도 미끄러지지 않는다 → 이 코너는 속도 제한이 없다
(호출하는 쪽에서 직선 최고 속도로 자른다).

```ts
  return Math.sqrt((mu * g) / denom);
}
```
`v_max = √(μ g / 분모)`.

### 7-2. 가속·제동 — `simulateLap` 안의 `accel`, `decel`, `step` (`src/physics/lapsim.ts`)

```ts
  const longGrip = (i: number, v: number) => {
    const total = at(aero.mu, i) * normal(i, v);
    const lat = m * v * v * Math.abs(track.kappa[i]);
    return Math.sqrt(Math.max(0, total * total - lat * lat));
  };
```
마찰원. `total` = μN (다운포스가 N 을 키움), `lat` = 구심력 m v² κ.
세로로 쓸 수 있는 힘 = √(total² − lat²). 코너 한계에서는 0, 직선에서는 μN 전부.

```ts
  const accel = (i: number, v: number) => {
    const engine = Math.min(P / Math.max(v, 0.5), longGrip(i, v));
    return (engine - dragF(i, v) - crr * normal(i, v)) / m;
  };
```
엔진 힘 = P/v 와 타이어 한계 중 작은 값. 뉴턴 제2법칙 a = (밀어 주는 힘 − 항력 − 구름 저항) / m.
`Math.max(v, 0.5)`: 정지(v = 0)에서 P/v 가 무한대가 되는 것을 막는다.

```ts
  const decel = (i: number, v: number) => (longGrip(i, v) + dragF(i, v) + crr * normal(i, v)) / m;
```
제동은 타이어 마찰 + 항력 + 구름 저항이 **모두 감속을 돕는다** (양수로 나타낸 감속도).

```ts
  const step = (from: number, to: number, v0: number, aFn: (i: number, v: number) => number) => {
    const a0 = aFn(from, v0);
    const vPred = Math.min(Math.sqrt(Math.max(0, v0 * v0 + 2 * a0 * ds)), vLimit[to]);
    const a1 = aFn(to, vPred);
    return Math.sqrt(Math.max(0, v0 * v0 + (a0 + a1) * ds));
  };
```
한 구간 진행. 등가속도 공식 `v₂² = v₁² + 2 a ds` 에서 a 를 **구간 양 끝 가속도의 평균**으로 쓴다
(Heun 방법). ① 시작점 가속도 a₀ 로 끝 속도를 예측 → ② 끝점 가속도 a₁ → ③ `v₂² = v₁² + (a₀ + a₁) ds`.
시작점 가속도만 쓰면 코너 출구에서 "한 칸씩 늦게" 가속하는 오차가 생겨 구간 길이에 따라 랩타임이 크게 변했다.

```ts
      tmp[j] = Math.min(step(i, j, tmp[i], accel), vLimit[j]);
```
전진 계산 한 줄: 최대 가속으로 간 속도와 다음 점 한계 속도 중 작은 값.

```ts
    bwdC[i] = Math.min(step(j, i, bwdC[j], decel), vLimit[i]);
```
후진 계산 한 줄: 뒤 점(j)에서 거꾸로 최대 제동한 속도와 앞 점 한계 중 작은 값.

```ts
    v[i] = Math.min(fwd[i], b);
```
전진(가속 한계)과 후진(제동 한계) 중 작은 쪽 = 실제로 낼 수 있는 속도.

### 7-3. 공기력 — `wingAero`, `carAero` (`src/physics/aero.ts`)

```ts
  const { cl: cl2d, cd: cd2d } = interpolateWing(t, angleDeg);
```
CSV 표에서 윙 각도에 맞는 2차원 C_L, C_D 를 선형 보간으로 찾는다.

```ts
  const cl3d = (cl2d * ar) / (ar + 2);
```
폭이 유한한 날개라 다운포스가 `AR/(AR+2)` 배로 줄어든다 (AR = 2 이면 절반).

```ts
  const cdInduced = (cl3d * cl3d) / (Math.PI * e * ar);
```
유도항력. 다운포스(C_L)의 제곱에 비례 → 윙을 세울수록 항력이 빠르게 커진다.

```ts
  return { ..., cls: cl3d * area, cds: (cd2d + cdInduced) * area };
```
계수 × 면적 = C_L·S, C_D·S.

```ts
  const cls = fw.cls + rw.cls + floor.cls + body.cls;
  const cds = fw.cds + rw.cds + floor.cds + body.cds;
```
`carAero`: 부품을 더하면 차 전체 값.

```ts
  const front = fw.cls + p.floorFrontShare * floor.cls;
  ... balance: cls > 0 ? front / cls : 0,
```
앞바퀴 쪽 다운포스 = 프런트 윙 전부 + 바닥의 앞쪽 몫 → 공력 밸런스.

예) 기본 셋업에서 C_L·S = 3.92 m². 300 km/h(83.3 m/s)에서
`F_down = ½ × 1.225 × 83.3² × 3.92 ≈ 16,700 N` → 차 무게(768 × 9.81 ≈ 7,530 N)의 약 2.2배.

## 8. 한계 (솔직하게)

- **절대 랩타임은 실제 F1 과 다르다.** 공력 계수·마찰계수 대부분이 가정값이다. 의미 있는 것은 셋업 변화의 경향.
- **첫 시케인 최저 속도(약 46 km/h)가 낮다.** 데이터 형상에서 레이싱 라인의 최소 반지름이 약 10 m 로 나온다.
  연석을 2 m 써도 10.8 m 정도라 최적화 문제가 아니라 데이터 형상(평활화된 OpenStreetMap)과 μ 가정에서 오는 차이다.
- 코너 꼭짓점에서 한계 속도 곡선을 그대로 따라갈 때 타이어 힘이 μN 을 최대 0.3 % 넘는다 (준정상 상태 방법의 이산화 효과).
- 코너 식(4장)은 항력을 무시한다. 시뮬레이션은 마찰원으로 항력을 이기는 데 필요한 힘까지 고려하므로 코너 속도가 식보다 아주 약간 낮다.
- 레이싱 라인은 근사, 섹터는 거리 3등분, 출발선 위치는 확인하지 못함.
- 엔진은 항상 최대 출력 (2026 규정의 배터리 에너지 한도 무시), 연료·타이어 마모·바람·경사 무시.

## 심화 참고: 컴퓨터 계산 기법

본문 이해에 꼭 필요하지는 않지만, "왜 결과가 믿을 만한가" 질문에 답할 때 쓸 수 있다.

| 기법 | 어디에 | 쉬운 설명 |
|---|---|---|
| 3차 스플라인 (`track.ts`) | 곡률 계산 | 5 m 간격 점들을 매끄러운 곡선으로 이어서 1 m 간격 점을 새로 찍는다. 꺾은선으로 이으면 꺾이는 점에서 곡률이 엉터리가 된다. |
| 곡률 공식 `κ = (x′y″ − y′x″)/(x′²+y′²)^{3/2}` | 곡률 계산 | 곡선이 얼마나 빨리 방향을 바꾸는지. 원이면 정확히 1/r (테스트로 확인). |
| 경사하강법 (`approximateRacingLine`) | 레이싱 라인 | 점을 조금씩 옆으로 옮겨 "꺾임 정도의 합"을 줄이는 일을 수천 번 반복. 트랙 밖으로는 못 나가게 막는다. |
| Heun 방법 (`lapsim.ts` 의 `step`) | 가속·제동 | 구간 처음과 끝의 가속도 평균을 쓰는 방법. 구간 길이를 절반으로 줄이면 오차가 약 1/3 로 줄어든다(4 → 2 → 1 → 0.5 m: 0.11 → 0.035 → 0.011 s). |
| 이분법 (`topSpeed`) | 최고 속도 | P = (항력 + 구름저항) × v 를 만족하는 v 를 "반씩 범위를 좁혀" 찾는다. |
