# 물리 계산 설명서 — 패널법은 어떻게 동작하는가

이 문서는 시뮬레이션의 계산 과정을 고등학교 물리·수학 수준에서 단계별로 설명한다.
뒷부분에서는 핵심 함수 3개를 **코드 한 줄씩** 해설한다 (면접 대비용).

- 형상 생성: `src/physics/naca.ts` → `generateNaca4`
- 패널법 계산: `src/physics/panel.ts` → `solvePanelMethod`
- 힘 계산: `src/physics/forces.ts` → `aeroForce`

---

## 1. 큰 그림

```
NACA 식 ──► 날개 좌표 141개 ──► 패널(선분) 140개 ──► 연립방정식 141개 풀기
                                                     │
                       ┌─────────────────────────────┘
                       ▼
           표면 속도 V ──(베르누이)──► 압력계수 Cp ──(압력 × 면적 합)──► C_L
                                                                         │
                                         F = ½ρv²SC  ◄──────────────────┘
```

1. 날개 모양을 수식으로 만든다 (NACA 4자리 식).
2. 표면을 짧은 직선 조각(**패널**) 140개로 나눈다.
3. 각 패널에 "소용돌이(와류)"를 깔고, 공기가 표면을 뚫지 않도록 소용돌이 세기를 정한다.
4. 소용돌이 세기로 표면의 공기 속도를 구한다.
5. **베르누이 법칙**으로 속도를 압력으로 바꾼다.
6. 압력을 표면 전체에 더하면 힘(양력 계수)이 된다.
7. 계수에 ½ρv²S 를 곱하면 실제 힘(N)이 된다.

## 2. 날개 모양 만들기 (NACA 4자리)

NACA 4412 = **최대 캠버 4 %, 그 위치 40 %, 두께 12 %**.

- **캠버선**(날개의 "뼈대", 휘어진 중심선): 앞쪽과 뒤쪽을 서로 다른 포물선으로 이어 붙인다.
- **두께**: 캠버선에 수직인 방향으로 위아래에 같은 두께를 붙인다.
  `y_t = 5t(0.2969√x − 0.1260x − 0.3516x² + 0.2843x³ − 0.1036x⁴)`
  - 마지막 계수는 원래 −0.1015 인데, 뒤끝을 정확히 닫기 위해 −0.1036 을 쓴다 (뒤끝 근처에서 시위의 0.1 % 차이).
- **코사인 간격**: 점을 앞전과 뒤끝에 촘촘하게 둔다. 앞전은 휘어짐이 커서 압력이 급하게 변하기 때문이다.
- **역방향(F1 윙)**: 모든 y 에 −1 을 곱한다. 원래 아랫면이 새 윗면이 된다.

## 3. 패널법의 아이디어

### 3-1. 왜 "소용돌이"인가

날개 주위 흐름 = **곧게 흐르는 바람** + **날개 주위를 도는 흐름(순환)** 으로 볼 수 있다.
도는 흐름이 있으면 한쪽 면은 바람과 같은 방향이라 빨라지고, 반대 면은 느려진다.
속도 차이 → (베르누이) 압력 차이 → 힘. 이 "도는 흐름"을 표면에 깔린 작은 소용돌이들로 표현한다.

### 3-2. 패널 하나가 만드는 속도

패널 위 소용돌이 세기 γ 는 패널 양 끝 값 γa, γb 사이에서 **직선으로** 변한다 (그래서 "선형" 와류 패널법).
점 소용돌이 하나가 거리 r 떨어진 곳에 만드는 속도는 `Γ / (2πr)` 이고 방향은 원을 따라 돈다.
이것을 패널 길이를 따라 적분하면, 결과는 두 가지 양으로 정리된다.

- **dθ**: 그 점에서 패널 양 끝을 바라본 각도 차
- **ln(r₁/r₂)**: 양 끝까지 거리 비의 로그

이 계산이 `linearVortexInfluence` 함수다.

### 3-3. 조건 두 가지 → 연립방정식

미지수는 패널 끝점(절점) 141개의 γ 값이다.

| 조건 | 개수 | 뜻 |
|---|---|---|
| **표면 통과 금지** (노이만 조건) | 140 | 각 패널 가운데 점에서 (바람 + 모든 소용돌이의 속도) · 법선 = 0. 공기가 날개 속으로 들어가지 않는다. |
| **쿠타 조건** | 1 | 뒤끝 윗면 γ + 뒤끝 아랫면 γ = 0. 공기가 뒤끝에서 매끄럽게 떠난다. |

141 × 141 연립방정식을 **가우스 소거법**으로 푼다.

> 쿠타 조건이 없으면? 순환의 크기가 정해지지 않아 답이 무한히 많다. "뒤끝에서 매끄럽게 떠난다"는
> 실제 관찰을 조건으로 넣어야 양력이 하나로 정해진다. 이 조건이 사실상 점성의 효과를 대신한다.

### 3-4. 속도 → 압력 → 힘

- 표면 접선 속도 `V` 를 구하면 베르누이 법칙으로 `Cp = 1 − (V/V∞)²`.
- 압력은 표면을 안쪽으로 민다. 패널마다 `−Cp × 법선 × 길이` 를 더하면 전체 힘이 된다.
- 이를 바람에 수직인 성분으로 나누면 양력계수 C_L (역방향이면 부호를 바꿔 다운포스 계수).
- 검산: 순환 Γ 로 구한 `C_L = 2Γ/(V∞c)` (쿠타–주코프스키 정리)와 1 % 안에서 같다.

### 3-5. 이 방법이 가정하는 것 (= 한계)

- **비점성**: 마찰이 없다 → 항력 0 (달랑베르의 역설), 실속 없음.
- **비압축성**: 밀도 일정 (풍속 ≪ 음속).
- **2차원**: 날개 폭이 무한하다 → 날개 끝 와류 없음.

그래서 점성 효과(항력, 실속, 레이놀즈 수에 따른 차이)는 NeuralFoil 로 미리 계산한 표를 쓴다.

### 3-6. 어떻게 검증했나

| 검사 | 결과 |
|---|---|
| NACA 0012, 0° 에서 C_L | 약 10⁻¹⁴ (≈ 0) |
| NACA 0012 양력 기울기 | 6.87 /rad (이론 2π(1+0.77t) = 6.86) |
| 패널 수 2배씩 늘릴 때 변화량 | 0.017 → 0.008 → 0.004 (절반씩 줄며 수렴) |
| NACA 4412 무양력각 | 패널법 −4.30°, 얇은 날개 이론 −4.15° |
| 독립 프로그램(AeroSandbox 4.2.10) 비교, 0°·5°·6° | 0.7~0.9 % 차이 |
| 역방향 ↔ 정방향 거울 대칭 | 10⁻⁸ 이내 일치 |

## 4. 핵심 함수 줄 단위 해설

### 4-1. 형상 생성 — `generateNaca4` (`src/physics/naca.ts`)

```ts
export function generateNaca4(code: string, options: AirfoilOptions = {}): Airfoil {
  const { m, p, t } = parseNacaCode(code);
```
"4412" → m = 0.04 (캠버 4 %), p = 0.4 (위치 40 %), t = 0.12 (두께 12 %).

```ts
  const n = options.panelsPerSide ?? 70;
  const inverted = options.inverted ?? false;
```
한쪽 면 패널 수(기본 70 → 전체 140)와 위아래 반전 여부. `??` 는 "값이 없으면 오른쪽 기본값".

```ts
  const xs = cosineSpacing(n);
```
x = ½(1 − cos β), β = 0 ~ π 를 n 등분 → 앞전·뒤끝에 촘촘한 x 위치 71개.

```ts
  for (const x of xs) {
    const { yc, dyc } = camber(x, m, p);
    const yt = thickness(x, t);
    const theta = Math.atan(dyc);
```
각 x 에서 캠버선 높이 `yc`, 기울기 `dyc`, 반 두께 `yt` 를 구한다. `theta` 는 캠버선이 기운 각도.

```ts
    upper.push({ x: x - yt * Math.sin(theta), y: yc + yt * Math.cos(theta) });
    lower.push({ x: x + yt * Math.sin(theta), y: yc - yt * Math.cos(theta) });
  }
```
두께를 캠버선에 **수직으로** 붙인다. 캠버선이 θ 기울어 있으면 수직 방향은 (−sinθ, cosθ) 이다.

```ts
  if (inverted) {
    const newUpper = lower.map((pt) => ({ x: pt.x, y: -pt.y }));
    const newLower = upper.map((pt) => ({ x: pt.x, y: -pt.y }));
```
역방향: y 부호를 바꾼다. 뒤집으면 원래 아랫면이 위로 올라가므로 윗면·아랫면 이름도 바꾼다.

```ts
  const coords = [...upper].reverse().concat(lower.slice(1));
```
Selig 순서로 잇기: 윗면을 뒤끝→앞전으로 뒤집고, 아랫면을 앞전 다음 점부터 붙인다.
앞전 점은 두 면이 공유하므로 한 번만 → 71 + 70 = **141개 점, 140개 패널**.

### 4-2. 패널법 — `solvePanelMethod` (`src/physics/panel.ts`)

```ts
  const panels = buildPanels(coords);
  const N = panels.length;
```
점 141개를 이웃끼리 이어 패널 140개를 만든다. 패널마다 길이, 방향(cos, sin), 바깥 법선(nx, ny), 가운데 점을 계산해 둔다.

```ts
  const Vinf = { x: Math.cos(alpha), y: Math.sin(alpha) };
```
자유흐름(바람) 속도. 크기 1, 받음각 α 만큼 기울어 있다. (모든 속도를 V∞ 로 나눈 무차원 값)

```ts
  const A = ... (N + 1) × (N + 1) 행렬, rhs = 길이 N + 1
  for (let i = 0; i < N; i++) {
    const pi = panels[i];
    for (let j = 0; j < N; j++) {
      const inf = linearVortexInfluence(panels[j], pi.mid.x, pi.mid.y, i === j);
```
패널 i 의 가운데 점에서, 패널 j 위 소용돌이(γa = 1 또는 γb = 1)가 만드는 속도를 구한다.
`i === j` 는 "자기 자신 위의 점"이라는 표시 (바로 위에서는 바깥쪽에서 본 값을 쓴다).

```ts
      A[i][j] += inf.ua * pi.nx + inf.va * pi.ny;
      A[i][j + 1] += inf.ub * pi.nx + inf.vb * pi.ny;
```
그 속도를 패널 i 의 **법선 방향 성분**(내적)으로 바꿔 행렬에 넣는다. 절점 j 는 패널 j 의 시작점이자 패널 j−1 의 끝점이라 두 번 더해진다.

```ts
    rhs[i] = -(Vinf.x * pi.nx + Vinf.y * pi.ny);
```
노이만 조건: (소용돌이들의 법선 속도 합) + (바람의 법선 속도) = 0 → 바람 몫을 오른쪽으로 넘긴다.

```ts
  A[N][0] = 1;
  A[N][N] = 1;
  rhs[N] = 0;
```
마지막 줄 = 쿠타 조건 γ₀ + γ_N = 0 (뒤끝의 윗면 끝 절점과 아랫면 끝 절점).

```ts
  const gamma = solveLinearSystem(A, rhs);
```
가우스 소거법으로 141개 γ 를 구한다.

```ts
    let u = Vinf.x;  let v = Vinf.y;
    for (let j = 0; j < N; j++) { u += ...γ; v += ...γ; }
    const vti = u * pi.cos + v * pi.sin;
    cp.push(1 - vti * vti);
```
패널마다 (바람 + 모든 소용돌이) 속도를 더해 **표면 방향 성분** V 를 구하고, 베르누이 법칙 `Cp = 1 − V²` 로 압력계수를 만든다.

```ts
    const dfx = -cp[i] * pi.nx * pi.length;
    const dfy = -cp[i] * pi.ny * pi.length;
    fx += dfx;  fy += dfy;
```
압력은 표면을 안쪽(−법선)으로 민다. "압력 × 넓이" 를 모든 패널에 대해 더한다.

```ts
  const cl = -fx * Math.sin(alpha) + fy * Math.cos(alpha);
```
전체 힘을 **바람에 수직인 방향** (−sinα, cosα) 으로 내적 → 양력계수. 역방향 날개는 이 값이 음수이고, 다운포스 계수 = −C_L.

```ts
  const cdPressure = fx * Math.cos(alpha) + fy * Math.sin(alpha);
```
바람 방향 성분 = 압력항력. 이론상 0 이어야 하고 실제로 0.003 정도(패널 근사 오차)만 남는다.

### 4-3. 힘 계산 — `aeroForce` (`src/physics/forces.ts`)

```ts
export function aeroForce(rho: number, v: number, area: number, coefficient: number): number {
  return dynamicPressure(rho, v) * area * coefficient;
}
```
`F = ½ρv² × S × C`.

- `dynamicPressure(rho, v)` = ½ρv² : 동압 [Pa]. 실험 모형(6 m/s, ρ = 1.2)이면 ½ × 1.2 × 36 = **21.6 Pa**.
- `area` = 시위 × 폭 = 0.1 m × 0.2 m = **0.02 m²**.
- `coefficient` = 다운포스 계수(또는 항력계수).

예) C_L = 0.534 (점성, 6°, Re 40,000) → F = 21.6 × 0.02 × 0.534 = **0.231 N** → 0.231 ÷ 9.8 × 1000 = **23.6 g**.

v 가 제곱으로 들어가므로 **풍속 2배 → 힘 4배** (계수가 같다면). 점성 데이터에서는 풍속이 바뀌면 Re 도 바뀌어 계수가 달라지므로 정확히 4배가 되지 않는다.
